Use these to test case fit and the snap hooks in each colour. Buy more only after a case passes. Grey is the planned shell colour.

Print settings (Neptune 3 Pro, brass nozzle): 235-245 °C nozzle, 70-80 °C bed, 30-50% fan so the hook layers bond, glue stick or textured PEI. Dry the roll if it strings.

Plain PETG only. Carbon-fibre PETG is stiffer and more brittle, so the snap hooks are more likely to crack, and it wears out a brass nozzle.
